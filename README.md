# Sales and Finance Analytics using Advanced Excel

## Project Overview

This project focuses on analyzing sales and financial performance using Microsoft Excel. It presents business data through structured reports and dashboard exports to help evaluate revenue trends, profitability, customer performance, market performance, and product sales.

## Project Objectives

- Analyze sales performance across customers and markets.
- Evaluate financial performance using Profit and Loss (P&L) reports.
- Compare market performance against targets.
- Identify top-performing products.
- Examine newly introduced products and their sales performance.
- Present business metrics in a clear, decision-oriented format.

## Reports and Analysis

### 1. Finance Analysis
- **P&L by Fiscal Months** — Monthly net sales, cost of goods sold (COGS), gross margin, and gross margin percentage.
- **P&L by Fiscal Years** — Yearly financial performance and year-over-year comparisons.

### 2. Sales and Customer Analysis
- **Customer Performance** — Customer-level net sales across years and growth comparisons.
- **India Customer Performance** — Customer sales performance within the Indian market.

### 3. Market Analysis
- **Market Performance vs Target** — Country-level sales and performance against targets.

### 4. Product Analysis
- **New Products 2021** — Sales performance of products introduced in 2021.
- **Top 5 Products** — Highest-ranked products by quantity.
- **Top 10 Products** — Product-level sales comparison and growth.

## Tools and Techniques

- Microsoft Excel
- Advanced Excel reporting and analysis
- Financial performance analysis
- Sales and customer analysis
- Target-versus-actual comparisons
- Year-over-year growth analysis
- Pivot tables, charts, and conditional formatting, where used

## Repository Structure

- `README.md` — Project overview and report descriptions

## Project Purpose

The purpose of this project is to demonstrate how Excel-based business reporting can help organize sales and financial data, evaluate business performance, and communicate useful insights to stakeholders.
